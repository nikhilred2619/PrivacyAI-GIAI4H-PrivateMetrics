# Public reference-task fixture (`idrid-dr-grading`)

**Public data only.** Nothing in this directory is private host data, and the
DP mechanism protects nothing here: these labels are published upstream. They
are used to measure correctness and the fidelity gap on the reference task
(conformance specification §4), not to demonstrate protection of secret labels.

| File | Provenance |
|---|---|
| `labels.csv` | Copied byte-for-byte from `FG-AI4H/oci-platform`, `packages/database/seed/fixtures/idrid-grading-demo/test-labels.hidden.csv`, at commit `5785db81b4193ff4e3d62738b3a3ea40f0f9aee8` (identical at `1da3bbf`). SHA-256 `83e8a543ae604e83a95d3f29bc77a1589f7bdf19e1565354d314cb3c9ff779b3`. The same 30 grades are seeded as the task's `ground_truth` in upstream `packages/database/seed/demo.sql` (task `idrid-dr-grading`, `num_classes` 5, `referable_threshold` 2). Columns `Image,dr_grade,dme_risk`; only `dr_grade` is used. |
| `predictions/*.json` | **Synthetic** prediction fixtures, generated by `make_prediction_fixtures.py` (seed 20261022) as perturbations of the labels above. Upstream publishes no baseline predictions for this task, so these stand in for models of known quality. They are not outputs of a real model. `python fixtures/reference/make_prediction_fixtures.py --check` verifies they are regenerated exactly. |
| `host.json` | Host configuration for running the host-side scorer on the reference task (used by the fidelity experiment and the demo). |

Class counts (grades 0–4): 7, 5, 6, 6, 6. Referable (grade ≥ 2): 18 of 30.

**Source data:** Indian Diabetic Retinopathy Image Dataset (IDRiD), Porwal et al., *Data* 3(3):25, 2018, https://doi.org/10.3390/data3030025. Licence CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). The upstream slice selected 30 testing-set images and downsampled them; this repository copies only the grade labels, not the images.

The upstream fixture does not identify patients, so the number of images per patient in this slice is **unknown**. The reference configuration declares a group factor of 2 (at most both eyes of one patient) as an **unverified, conservative assumption**; see `docs/OPERATIONAL_ENVELOPE.md` §10.
