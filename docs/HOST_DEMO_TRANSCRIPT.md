## 5–8. Preflight, scoring with production OpenDP noise, ledger reservation, metric release

Preflight checks the dispatch and the remaining budget before the model runs. `host-score` validates the predictions, reserves ε in the ledger (one `BEGIN IMMEDIATE` transaction), draws OpenDP discrete-Laplace noise, post-processes and records the release, and prints the only body that leaves the host.

```console
$ python -m privatemetrics host-preflight --config host-private/host.json --dispatch dispatch-66a14c0e.json
{"proceed": true}
[exit 0]
```

```console
$ python -m privatemetrics host-score --config host-private/host.json --dispatch dispatch-66a14c0e.json --worker-result worker-a.json

[exit 0]
```
